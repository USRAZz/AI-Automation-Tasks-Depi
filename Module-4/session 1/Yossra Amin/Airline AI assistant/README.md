# Module 4 - AI Automation Projects

This repository contains the practical work and projects completed for Module 4.

## Project Structure

* **Module-4/session 1/Yossra Amin/**
  * **SVG Generation Pipeline**: A modular, local AI-assisted SVG generation pipeline using Jupyter Notebook, Gradio concepts, and the OpenAI client SDK configured with the Groq API (`openai/gpt-oss-120b`). It features standardized request handling, timing measurements, and visual SVG rendering within the environment.
  * **Airline AI Assistant**: An AI assistant project implemented and integrated into the workflow.

## Technologies Used
* Python
* Jupyter Notebook
* OpenAI SDK / Groq API (`openai/gpt-oss-120b`)
